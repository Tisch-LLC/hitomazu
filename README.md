# ひとまず テロップ素材（動画編集用）

背景透過の PNG です。「Code → Download ZIP」でまとめて取得できます。

- lower-light / lower-dark：下部テロップの枠（1920×1080、文字なし）
- title-light / title-dark：見出し用の枠（1920×1080、中央）
- tag-light / tag-dark：左上のタグ
- check-green / check-white / check-outline：チェックマーク（400×400）
- lockup-green / lockup-white：ロゴ＋「ひとまず」
- corner-light / corner-dark：隅に置く小さなロゴ
- logo-green / logo-white / logo-dark：ロゴマーク（800×800）
- sample-lower-light：文字を入れた見本

色：緑 #2f6b55、深緑 #1e4d3c、文字 #1f2a24、生成り #f7f5f0
