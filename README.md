# 実家のこれから（仮）

離れて暮らす地方の実家について、何から始めればよいか分からない人のための手続きナビです。Built with Claude: Japan 2026 の提出作品として制作中です。

最初に、1問ずつ答える質問に進みます。最初の質問で実家のいまの状況を4つから選びます。

- 持ち主は存命だが、施設などに移って空いている
- 持ち主がまだ住んでいて、将来に備えたい
- 親などが亡くなり、相続した（する予定）
- すでに自分や家族の名義で、空いている

状況に合わせて、「最低限やること」を次のグループに分けて示します。相続の手続きは、相続の場合だけ表示します。細かい条件（確定申告の有無など）は、リストの該当項目の上で「はい・いいえ」で答えられます。

- **期限があるもの**（相続の場合）：相続放棄（3か月）、準確定申告（4か月）、相続税（10か月）、相続登記（3年）、農地・森林の届出、空き家の3,000万円特別控除の売却期限
- **遠隔でできるもの**：持ち主の意向と判断能力の確認、登記事項証明書のオンライン請求、固定資産税の通知、郵便物・公共料金・火災保険など
- **次の帰省でやるもの**：書類の場所の確認、写真撮影、鍵、家財、近所への挨拶など
- **これからの方針を考える**：家族の希望の整理、建物の状態と耐震、田畑・山林の手続き、地元の相談先
- **放置しないための管理**：見回り、管理不全空家の勧告を避ける

各項目には、国や自治体の案内ページを根拠として付けています。

## 設計の方針

- チェックリストの中身は、出典を確認した固定データ（`src/domain/checklist.ts`）として持ちます。
- 当てはまるかどうかと期限の日付は、プログラムで計算します（`src/domain/dates.ts`）。単体テストで確かめています。
- 入力した内容は、ブラウザの中（localStorage）だけに保存します。
- このアプリは手続きの漏れを防ぐためのもので、法律・税務の判断を代わりに行うものではありません。

## 構成

```text
src/index.ts                 # Bun.serve によるサーバー（/api/status）
src/server/config.ts         # 環境変数からの Claude API の設定
src/index.html, frontend.tsx # フロントエンドの入口
src/App.tsx                  # 画面全体（はじめに → 質問 → やることリスト）
src/components/              # 質問の画面、やることリスト
src/domain/                  # チェックリストと質問のデータ、期限の計算、状況の型、デモ用の架空データ
src/storage.ts               # ブラウザへの保存
```

React 19、Tailwind CSS 4、TypeScript を使い、サーバーとフロントエンドを Bun の1プロセスで動かします。

## 使い方

[Bun](https://bun.com) 1.4 以降が必要です。

```bash
bun install   # 依存関係のインストール
bun dev       # 開発サーバー（ホットリロード）
bun test      # 単体テスト
bun check     # 型チェック
bun run build # dist/ へビルド
bun start     # 本番モードで起動
```

### Claude API の設定

```bash
cp .env.example .env
# .env の ANTHROPIC_API_KEY にキーを入れる（CLAUDE_MODEL は省略可、既定は claude-opus-5-5）
```

`.env` はコミットされません。キーはサーバー側だけで使い、画面には渡しません。`GET /api/status` で、設定済みかどうかとモデル名だけを確認できます。
